# GitHub Homepage — Preview Instructions

This folder contains the source code for my personal GitHub Pages homepage.

## How to preview locally

1. Open `index.html` in any web browser by double-clicking the file.
2. Or serve it with a local HTTP server:
   ```bash
   # If you have Python 3:
   python3 -m http.server 8000
   # Then open http://localhost:8000 in your browser.

   # If you have Node.js:
   npx serve .
   ```

## Deployment

The site is published at `https://<your-username>.github.io/`.
To deploy updates, push changes to the `main` branch of the `<your-username>.github.io` repository on GitHub.
